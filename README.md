# נוכחות אנשי מכירות

מערכת סימון נוכחות ודיווח יומי לאנשי מכירות שעובדים מרחוק.

- **בבוקר:** תזכורת בוואטסאפ ב-11:00 (ושוב ב-12:00 וב-13:00 למי שלא סימן). לוחצים "התחלתי" ומזינים כמה פולואפים מתוכננים.
- **בסוף היום:** תזכורת ב-18:00 (ושוב ב-19:00). לוחצים "סיימתי" ומזינים שיחות (לא חובה), סגירות לפי סוג, כמה כסף נכנס והערה.
- **לוח צוות:** כולם רואים את כולם, לפי יום, שבוע וחודש, עם ייצוא לאקסל.
- **סיכומים:** סיכום שבועי ביום העבודה האחרון ב-20:00, וסיכום חודשי ב-1 לחודש, נשלחים לכולם בוואטסאפ.

## ממה זה בנוי

| חלק | איפה |
|---|---|
| האתר (`app/`) | GitHub Pages. HTML/JS פשוט, בלי build |
| מאגר הנתונים, השעון והשליחה (`supabase/setup.sql`) | Supabase: Postgres + pg_cron + pg_net |
| שליחת וואטסאפ | Green API |

אין סיסמאות. לכל אדם יש קישור אישי עם קוד סודי. הטבלאות נעולות לגמרי, והאתר יכול רק לקרוא לפונקציות `app_*`, שבודקות את הקוד.

## התקנה (פעם אחת)

### 1. Supabase
1. פותחים פרויקט חדש ב-[supabase.com](https://supabase.com).
2. **SQL Editor → New query**, מדביקים את כל התוכן של `supabase/setup.sql` ולוחצים **Run**.
3. בסוף ההרצה מופיעה טבלה עם 3 שורות: מנהל, יפתח בדש וגל רז. שומרים את ה-token של "מנהל".
4. **Project Settings → API**: מעתיקים את **Project URL** ואת המפתח הציבורי (**publishable** או **anon**) לקובץ `app/config.js`.

### 2. האתר
אחרי שדוחפים ל-`main`, האתר עולה אוטומטית ל-`https://<user>.github.io/sales-attendance/`.
(ב-GitHub: **Settings → Pages → Source: GitHub Actions**.)

### 3. Green API (וואטסאפ)
1. נרשמים ב-[green-api.com](https://green-api.com), יוצרים instance ומחברים מספר וואטסאפ בסריקת QR. מומלץ מספר נפרד ולא המספר האישי.
2. מעתיקים את **apiUrl**, **idInstance** ו-**apiTokenInstance**.

### 4. מסך הניהול
פותחים `https://<user>.github.io/sales-attendance/?t=<token של המנהל>` → לשונית **ניהול**:
1. **כתובת האתר** → "הכתובת הנוכחית" → שמירה.
2. ממלאים את פרטי Green API → שמירה.
3. לכל איש מוסיפים טלפון (ומשנים את השם "מנהל" לשם שלך), ולוחצים **הודעת בדיקה**.
4. **העתקת קישור** ושליחה לכל אחד. אנשי המכירות שומרים את הקישור כאייקון במסך הבית.

## שינויים נפוצים
- **שעות וטקסט התזכורות:** מסך ניהול → תזכורות וסיכומים.
- **ימי עבודה:** מסך ניהול → הגדרות.
- **איש מכירות חדש / עזב:** מסך ניהול → אנשים (הוספה, או עריכה → לא פעיל).
- **קישור דלף:** עריכה → "ביטול הקישור הישן ויצירת קישור חדש".
